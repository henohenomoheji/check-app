# 関連ナレッジ判定アプリケーション 設計タスク一覧

## 1. 目的・対象範囲

ユーザーが入力した**概要テキスト**と**アップロード資料**をもとに、登録済みナレッジから関連資料を判定するアプリケーションを設計する。過去の会話を左サイドバーから開き、文脈を引き継いで追加質問できるようにする。

### 対象機能

- 概要テキスト入力（テキストのみ／ファイルのみ／両方の入力を想定）
- ファイルアップロードとAzure Document Intelligenceによる解析
- Azure OpenAIによる既存ナレッジの関連性判定・理由表示
- 判定結果への追加質問とAI回答
- 会話履歴の保存・一覧表示・再開

### 想定技術

| 領域 | 技術 |
|---|---|
| フロントエンド | Next.js |
| API・業務ロジック | Azure App Service |
| ファイル・解析結果保存 | Azure Blob Storage |
| 文書解析 | Azure Document Intelligence |
| 判定・回答 | Azure OpenAI |
| 永続データ | Azure Database for PostgreSQL |
